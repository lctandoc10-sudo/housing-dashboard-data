# Clickable preview

`precast-cmms-preview.html` is a single-file, clickable preview of the CMMS with a snapshot of 90 days of demo data. Download it and double-click it to open it in any browser; no installation is needed. It needs an internet connection for the charts and QR codes.

Changes you make in the preview are not saved; they reset when the page is reloaded. The real application is the rest of the `cmms/` folder (see `../README.md`).
