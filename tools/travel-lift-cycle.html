How it's computed

Loaded travel = |bed − rack| ÷ loaded speed + accel/decel.
Empty return = |rack − bed| ÷ empty speed + accel/decel (or 0 if the return box is off).
Basic cycle = fixed elements + loaded travel + empty return.
Standard cycle = basic × (1 + PF&D %). Panels/hour = 3600 ÷ standard × utilisation.
